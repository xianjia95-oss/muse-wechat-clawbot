# v0.4.0-rc.6 并发队列验证

日期：2026-10-22。rc.6 候选源码的本地验证，未部署至 Muse 云端、未发布 Release。源码提交不等于完成部署或生产验收。没有新增运行依赖；不包含本地内存/服务器压力工具或其报告。

## 实现与检查范围

- 私密持久化队列、SQLite 进程间调度锁、全局与 io/cpu 名额同时限制。兼容默认 2/2/2，显式配置部署建议 4/4/1，排队 64，全部记录上限 256。
- 完成自动补位、CPU 满时跳过启动较早可运行 IO、限额降低不杀现有工具、异常后的显式 dispatch。元数据及新 job 目录先 fsync，再允许可信脚本执行。
- 稳定 job ID 去重保持；取消和过期不复活，启动许可在未来一小时内。排队后的正常续租须由真实 worker 执行，成功后显式 refresh。helper 不访问桥 token，不重试外部工具、不回复或 ack。
- pending/status 只读且不存在目录时不创建；hook 对可运行/过期的 queued 和完成结果唤醒。排队很久后刚被启动的 job 使用 dispatched_at 计算监督器启动宽限，避免误报失联。
- Muse 环境反馈可用原生并行后，增加轻量调度者、独立原生执行者及每事件唯一所有者/私密交接协议；工具池名额不再作为 Muse 任务总数限制。桥原有独立事件租约无需改动，实际原生创建/接管仍由部署环境执行。

- 本轮审计及自动消费诊断修复后的 Windows / Node 24.14.1：122 项，103 通过、19 项 Linux 专用测试跳过、0 失败。
- Linux / Node 24.22.0：复制相同源码和依赖至容器 Linux 本地文件系统，122 项全部通过。早期直接读取 Windows bind mount 时，原有媒体 CLI 测试两次达到 20 秒 runner 超时；未改该用例的业务代码、断言或超时值，本地 Linux 文件系统完整复测通过。生产状态仍须使用持久化本地磁盘。
- 新增 8 项回归：10 个 io/cpu 混合任务自动补位，四个后台 HTTP 等待期间完成 10 条模拟短回复；8 个独立进程重复提交同一 ID 仅执行一次；独立进程不同任务竞争遵守 IO/CPU/总上限；队列满不覆盖已有记录、queued 取消和过期不执行；期限刷新、跨进程 dispatch 恢复；策略/期限拒绝、缺目录只读与启动宽限。
- 再增加 3 项独立 HTTP 客户端回归：10 次并行领取得到不同事件/token，后领取任务先完成即可回微信且首任务仍未 ack，期间新事件可处理；串用 token 的 reply/renew/checkpoint/ack 均被拒且不改他人事件；旧租约拒绝而无关任务继续，5 次同 ID 并发最终回复只发送一次。本地客户端仅模拟执行者，不声称启动过真实 Muse 子任务。
- Linux 安装冒烟通过：安装、失败阶段隔离、运行中拒绝、升级备份、回滚、私密配置；真实 hook 脚本可在空 inbox 下发现完成和 runnable queued，检测不执行工具。systemctl 为隔离替身。
- 新增 7 项故障/恢复回归：发布中断不阻塞队列且不执行未发布工具；成功/失败任务清理脚本后仍缓存去重；取消标记竞争幂等；交接文件目录同步失败则领取前终止；媒体同步失败不发送、不保存快照引用、不 ack；备份失败不发布且可重试；恢复暂存同步失败保留原状态。具体修复见 [审计报告](AUDIT_v0.4.0-rc.6.md)。
- 再补 2 项领取进展回归：十条消息等待90秒、仅有空领取计数时，readiness/diagnose报告worker_claim_gap且不领取、不ack、不发送；真正领取后重新计算观察期。覆盖自定义阈值、已全领取、缺遥测与近期成功领取；不把outcome=wake、桥计数或本地客户端当作原生投递/进程存活证明。旧配置兼容及旧桥诊断测试同步通过。
