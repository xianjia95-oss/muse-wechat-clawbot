# Muse Link v0.4.0-rc.2

本候选修复版解决任务取消后占租约、排队/上传后旧 worker 继续发微信、旧版回执提前清理，以及备份恢复路径边界等问题。新增 13 项回归测试，Windows/Linux 各 73 项测试通过；本地收发、60 秒模拟压力和 Linux 安装回滚通过。未新增运行依赖。

- 发送前重新校验租约，过期回复不再发起后续 chat 请求；保留已上传引用和已确认分段供当前 worker 恢复。
- 未完成任务存在时保留无关联的旧 Muse 回执，避免丢失恢复去重依据。
- 真实路径边界覆盖父目录符号链接和 junction，恢复禁止与备份源重叠或覆盖 HOME/其祖先。
- 拒绝公开示例 token、无效配置选项和非字符串步骤；严格 JSON MIME，畸形请求 ID 返回 400。
- 修正明确 --limit 1 和重新扫码前停服务的指令，补齐安全信任边界。

暂停 hook、停止服务、备份后升级，保留配置/状态并同步 worker 指令。原 init 随机 token 和合规 Base64 token 可继续使用；自定义 token 必须为 32..256 个无空格可见 ASCII 字符。部署说明见 docs/MUSE.md，审计与验证记录见 docs/AUDIT_v0.4.0-rc.2.md 和 docs/VALIDATION_v0.4.0-rc.2.md。
