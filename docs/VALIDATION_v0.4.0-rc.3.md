本轮另做 Windows 10 秒本地 HTTP/SQLite 压力运行：204 个任务、204 次缓存重试、1 次关闭重开、0 条重复上游消息，峰值 pending=4。模拟上游每次等待 5ms，桥耗时 p50=46.83ms、p95=91.51ms，峰值状态目录 4,591,120 字节、RSS 105,779,200 字节。这是短时模拟，不能推算实际微信或 Muse 耗时，也不是生产稳定性结论。

真实反馈中的“领取后被 stale_lease 拒绝、未确认任务等待租约到期”属于待排查失败。后续班次已没有原 token，无法验证失败时的 token 比对，不能据此认定重启造成租约错乱。两条本地重启路径通过也不能否定该事件的实际失败。本版补足具体拒绝原因、服务端时间、ack 来源和私密交接文件，仍需保存云端失败当时的脱敏错误 JSON、退出码及实际任务状态。
