# Muse Link v0.4.0-rc.1

本版为单账号、单实例长期运行增加运维保护，继续使用 Node.js 24 + 内置 SQLite，未增加运行依赖。适用于在真实 Muse 云端进行上线验收；仍需完成手机收取/播放、真实 hooks 和 72 小时运行测试。

- 操作系统释放的状态独占锁，阻止同一状态的第二实例和运行中离线维护。
- 当前租约 token 校验、续租、工具步骤日志和中断后核对，减少旧 worker 与重复操作风险。
- 有界收发队列、HTTP 并发、磁盘/媒体预算、过载重试提示与 readiness。
- 定期历史及媒体维护；默认 7 天已完成事件、90 天发送幂等记录，未决结果保留。
- 校验清单的离线备份、恢复后的强制核对闸门、升级前备份、候选目录切换和代码回滚。
- Windows/Linux 故障测试、安装/回滚模拟、本地 HTTP stress 和真实部署的只读观测工具。

升级会默认开启 require_lease_token=true：**暂停旧 hook、停止服务、备份并升级后台、同步更新 worker 指令后再启动。** 旧 worker 未传 lease_token 会被拒绝。见 [生产运行与验收](PRODUCTION.md)、[部署说明](MUSE.md) 和 [升级指令](给Muse升级的指令.txt)。

发送 unknown 不自动重试，工具步骤 started 未完成不自动重复。备份恢复后不能直接执行任务，须核对外部结果再批准恢复。发送去重存在保留期限，不保证外部工具任意故障下恰好执行一次；也不提供多副本高可用。媒体能力沿用 v0.3：出站图片/视频，入站附件下载仍未实现。
