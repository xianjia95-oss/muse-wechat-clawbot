# Muse Link v0.3.0

Muse Link 将 Meta Muse 连接到微信 ClawBot，直接使用腾讯 iLink 协议。回复提交后立即发送，接收、发送与媒体上传使用独立连接池；通过请求 ID 和耗时记录定位“任务完成后微信回传很慢”的问题。使用 MIT 许可证。

本版支持文字双向交接，以及 Muse 生成图片、视频后回传微信。包含任务领取、自动路由、进度回复、SQLite 持久化、发送去重、失败恢复、扫码与手机配对验证码，以及 Linux systemd 部署。

图片支持 PNG/JPEG/GIF/WebP，单张上限 20 MiB；视频支持 MP4/MOV，单个上限 50 MiB，不转码。以上为项目本地限制，服务端仍可能拒绝。入站图片、视频、普通文件和原始语音下载尚未实现。

需要 Node.js 24+。下载 `muse-link-v0.3.0.zip` 后，按包内 `docs/MUSE.md` 部署；已有 v0.2.x 部署按升级步骤保留原配置、登录与数据库。下载后可用同名 `.zip.sha256` 校验文件。

本地模拟测试覆盖任务、文字及媒体协议、加密、顺序、去重和恢复；真实 Muse hooks、微信手机收取和视频播放仍待部署验收。微信接口 accepted 不代表手机已显示。项目没有真实微信速度承诺，与 Meta、腾讯无官方隶属关系。
